# Остаток — учёт расходов

Мини-приложение: задаёте сумму на месяц (например, зарплату), каждый день записываете траты, а программа показывает остаток, сколько можно тратить в день и остаток по дням или по 5 дней. В полночь день меняется сам, 1-го числа начинается новый месяц.

Работает двумя способами из одних и тех же файлов:

| | Где открывать | Где хранятся записи |
|---|---|---|
| **Telegram Mini App** | в Telegram, кнопкой в вашем боте | в облаке Telegram у каждого пользователя: не теряются при смене телефона |
| **Приложение на iPhone / Android** | Safari → «Поделиться» → «На экран „Домой“» | только на этом телефоне (есть резервная копия в файл) |

Каждый человек видит только свои записи. Сервер и база данных не нужны.

---

## 1. Выложить в интернет (GitHub Pages, бесплатно)

Telegram открывает мини-приложения только по адресу `https://…`, поэтому файлы нужно где-то разместить.

1. Зарегистрируйтесь на <https://github.com> (если ещё нет аккаунта).
2. Нажмите **New repository** → имя, например `ostatok` → **Public** → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащите **все файлы и папки** из этого архива (`index.html`, `app.js`, `icons/` и остальные) → **Commit changes**.
4. **Settings → Pages** → *Source*: **Deploy from a branch** → *Branch*: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/ostatok/`. Откройте его, чтобы проверить.

## 2. Подключить к Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте название (например «Остаток») и имя бота, которое заканчивается на `bot` (например `ostatok_rashod_bot`).
2. BotFather пришлёт токен. **Никому его не показывайте**; для этого приложения он не нужен.
3. `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button** → отправьте адрес из шага 1.5 → отправьте подпись кнопки, например `Открыть`.
4. По желанию: **Bot Settings → Configure Mini App → Enable Mini App** с тем же адресом. Тогда ссылка `https://t.me/ИМЯ_БОТА?startapp` открывает приложение сразу.

Готово. Знакомым отправляете ссылку `https://t.me/ИМЯ_БОТА`: они жмут **Start**, затем кнопку **Открыть** слева от поля ввода.

## 3. Как знакомые ставят его на iPhone без Telegram

1. Открыть адрес `https://ВАШ-ЛОГИН.github.io/ostatok/` **в Safari**.
2. Нажать **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **Добавить**.
3. На экране появится иконка «Остаток». Приложение открывается без адресной строки и работает без интернета.

На Android: открыть адрес в Chrome, и программа сама предложит **Установить**.

> Записи в таком режиме хранятся на телефоне. Перед сменой телефона: внизу приложения **«Сохранить копию»**, а на новом телефоне **«Восстановить из файла»**.

## Как обновить приложение

1. Замените изменённые файлы в репозитории на GitHub.
2. В файле `sw.js` увеличьте номер в строке `const VERSION = "ostatok-v1";` (например, на `ostatok-v2`), иначе установленные на телефон копии могут показывать старую версию.

Записи пользователей при обновлении не пропадают.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | разметка экрана |
| `styles.css` | оформление, светлая и тёмная тема |
| `calc.js` | расчёты: остаток, норма в день, строки «по дням» и «по 5 дней» |
| `storage.js` | хранение: телефон + облако Telegram (CloudStorage) |
| `app.js` | работа экрана, смена дня в полночь, Telegram, установка |
| `sw.js` | работа без интернета для установленного приложения |
| `manifest.webmanifest`, `icons/` | название и иконка приложения на телефоне |
| `tests/` | автоматические проверки |

## Проверки (для разработчика)

Нужны Node.js 20+ и Playwright с Chromium:

```bash
npm install
npx playwright install chromium
npm test
```

Проверяется: расчёт остатка и нормы в день, разбивка по 5 дней, наследование суммы на следующий месяц, переход на новый день и месяц в 00:00, сохранение в облако Telegram (в том числе длинные месяцы и повторная отправка после обрыва связи), резервная копия.

## Ограничения

- Облако Telegram даёт каждому пользователю 1024 ячейки по 4 КБ. Месяц с ~70 записями занимает 1 ячейку, так что места хватит на много лет.
- Если открыть приложение одновременно на двух телефонах и записывать в один и тот же месяц, сохранится версия того телефона, который записал последним.
- Валюта в интерфейсе — «сум»; меняется в `index.html` (слово `сум`) и в подписях `app.js`.
